# WeChat Ink · 微墨

微信公众号写作、配图与排版助手，由 **Snowwit88** 开发与维护。

把公众号文章从选题、资料研究、写作、配图、排版，推进到微信草稿箱的一套 AI 技能与配套工具。

默认采用低饱和学术风，适合研究型长文、知识解释和观点分析。需要支持本地文件与脚本的 AI 客户端；它不是独立聊天软件。

## 可以做什么

| 环节 | 功能 |
|---|---|
| 调研 | 查找原始来源、核对日期与数据口径、保留交叉资料 |
| 写作 | 围绕一个具体问题组织正文，区分事实与判断 |
| 审校 | 检查空话、机械表达、引用和内容边界 |
| 配图 | 默认 1 张封面＋6 张正文图，低饱和学术风 |
| 排版 | Markdown 转微信公众号 HTML，支持参考资料与长 URL 折行 |
| 交付 | 本地预览；配置好自己的账号与固定出口后创建微信草稿并回读 |

自动化停在草稿箱，不正式群发。文稿与本地排版可先使用；生图、微信 API 分别需要自己的服务配置。

## 快速开始

下载本仓库 ZIP 并解压，或克隆后进入项目目录。需要 Python 3.10 或更高版本：

```sh
python3 install.py
```

安装器会创建独立环境并安装依赖，不覆盖已有同名技能。Windows 原生可使用 `py install.py`；自动草稿的固定出口流程需在 WSL 内安装和运行。

也可把项目文件夹交给 AI 并复制 [安装与首次使用提示词](GETTING_STARTED.md)。详细配置与离线示例见 [使用说明](wechat-ink/README.md)。

## 你需要准备什么

- 可读本地文件、运行脚本的 AI 助手；研究任务还需联网搜索。
- Python 3.10+；默认 Python 生图入口无需 Bun。
- 自动生图：自己的 OpenAI 兼容生图服务配置。模型、尺寸和返回格式需服务商支持。
- 自动微信草稿：自己的公众号开发者凭证、相应接口权限、固定出口服务器与白名单。

凭证仅在本机配置，不发到聊天，不提交仓库。没有自动发布条件时，仍可完成文稿与预览，手动在微信后台编辑图文。

```sh
python3 -m pytest wechat-ink/tests -q
```
