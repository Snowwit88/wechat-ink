# 发布检查表

## 内容

- [ ] 标题与正文回答的是同一个问题
- [ ] 关键数字已核对口径、时间和原始来源
- [ ] 事实、转述与作者判断能够区分
- [ ] 已检查反方观点，没有把争议写成定论
- [ ] 没有荐股、保本、必赚或个性化投资承诺

## 文字与排版

- [ ] 首屏能在 5 秒内说清问题
- [ ] 标题、摘要、封面三者不重复堆叠
- [ ] 小节标题统一为“中文序号＋主题”，没有“六、第六层”这类重复编号或层级标签
- [ ] 没有为排版反复破坏已确认的第一版风格
- [ ] 所有图片人物肢体、文字、数字和因果箭头均经人工检查
- [ ] 引用写明机构／作者、题名和日期；所有交叉来源的完整 URL 已保存在 `research.md`
- [ ] 正文每条参考资料只保留一个内容完整、与题名匹配且可访问的 URL，没有并列重复来源
- [ ] 参考资料使用阿拉伯数字编号；来源行以中文分号收尾，完整裸 URL 紧接下一行，没有使用 Markdown 外链或外部 `<a>` 标签
- [ ] 每条“来源＋URL”是同一个紧凑条目；参考文字为 14.5px、URL 为 12.5px，URL 行无首行缩进且上方仅保留 2px 间距

## 手机预览

- [ ] iPhone/Android 至少预览一次
- [ ] 序号、标点与正文没有异常换行
- [ ] 图片没有被裁掉主体或说明
- [ ] 长表格、裸 URL 和英文术语没有撑破宽度；裸 URL 换行后没有异常左侧空白
- [ ] 封面在消息卡片和公众号主页两种裁切下都可识别

## 微信后台

- [ ] 已运行 `./operations/wechat-egress.sh check`，确认出口是公众号白名单中的固定服务器 IPv4
- [ ] 创建草稿使用 `./operations/wechat-egress.sh publish ...`，没有直接运行 `publish.py` 或回退到本机动态出口
- [ ] 草稿标题、作者、摘要和封面正确
- [ ] 原创标识、留言和转载设置按本篇需求选择
- [ ] 发布前从微信草稿再发一次手机预览
- [ ] 确认当前选中的是最终草稿，而不是后续测试版
- [ ] 群发由人工点击，自动化到草稿箱即停

## 发布后

- [ ] 回填永久链接和发布时间
- [ ] 加入对应合集
- [ ] D+1 和 D+7 记录核心数据
- [ ] 记录读者的真实疑问，作为下一篇选题线索
